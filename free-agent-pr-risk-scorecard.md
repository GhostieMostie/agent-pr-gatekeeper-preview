# Free Agent PR Risk Scorecard

Score each category from 0 to 2.

0 = missing or risky.  
1 = partial.  
2 = clear and reviewable.

| Category | Score | Notes |
| --- | ---: | --- |
| Linked issue or goal |  |  |
| Reproduction or before/after |  |  |
| Validation commands |  |  |
| CI status/classification |  |  |
| Scope size |  |  |
| Risk notes |  |  |
| AI disclosure/human validation |  |  |
| Bounty/claim clarity |  |  |

## Decision Bands

- 13-16: Review-ready.
- 9-12: Ask for targeted evidence.
- 5-8: Park until the contributor adds facts.
- 0-4: Reject or request a fresh, smaller PR.

## Safe Public Ask

```md
Thanks for the PR. Before review, please add the linked issue or goal, reproduction or before/after notes, validation commands, CI status/classification, and a human-validation note if AI assistance was used. That will make the change easier to review fairly.
```
